# 🤖 Local AI Desktop App

A feature-rich local artificial intelligence desktop application built via vibe coding that runs completely offline using **Ollama**, powered by a lightweight web interface and custom Windows Batch script wrappers.

---

## ✨ Features
* **100% Local & Private:** Runs entirely on your machine via Ollama with no external API keys required.
* **Screen Agent:** An intelligent agent that can view your screen, click, and type commands.
* **Type For Me:** An automated typing helper that can safely type out AI-generated content for you.
* **AI Groups & Multi-Agent Collaboration:** Create custom AI groups in settings and assign roles (which AI sees the screen, executes actions, or handles both). You can then select your created group inside the Screen Agent tab.
* **Voice, Call AI & Camera:** Voice calls, text-to-speech support, and camera integration.
* **Custom Personas & Models:** Complete control over AI system prompts, custom models, and local settings.

---

## 📋 Prerequisites & System Requirements
* **OS:** Windows 11 recommended (Windows 10 supported maybe)
* **Ollama:** Required to host and run local AI models.

---

## 🚀 How to Set Up & Run

### 1. Install Ollama & Download Models
* If you haven't installed Ollama yet, double-click **`RUN_TO_INSTALL_OLLAMA.bat`** to ensure it installs correctly on your PC.
* You can also use **`RUN_TO_INSTALL_OLLAMA.bat`** to quickly chat directly with the AI in a simple terminal interface.
* Once the main app is open, go to **Settings** $\rightarrow$ **Manage Models** to download your preferred local models.

### 2. Launching the Main Desktop App
* Double-click **`RUN_APP_HERE.bat`** to launch the full app and access every feature.
* Keep the command prompt window open while using the app (closing it will stop the local background server).

---

## 💡 Quick Tips & UI Navigation
* **Finding Appearance Settings:** To customize themes and accent colors, open **Settings** and under **Camera** click the empty button tab at the bottom of the left sidebar.
